# 🛡️ DGS Sentinel AI

AI-powered cloud exposure management and security analytics platform built using AWS, Python, Streamlit, OpenAI APIs, and Boto3.

## Features

- AWS EC2 asset discovery
- IAM visibility
- Security group analysis
- Open port detection
- Risk classification
- AI-generated remediation guidance
- Executive cloud security reporting
- CSV export capability

## Technologies

- Python
- AWS EC2
- AWS IAM
- Boto3
- Streamlit
- OpenAI API
- Pandas
- Plotly
